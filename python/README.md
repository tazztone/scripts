# Python Scripts

A collection of utility scripts for various Python-based tasks.

## Scripts

### [compress_png_to_webp_and_keep_comfyui_workflow](./compress_png_to_webp_and_keep_comfyui_workflow/)
A high-performance, parallelized script to convert ComfyUI PNG images to WebP format while preserving essential generation metadata (workflows and prompt graphs for WAS Node Suite / ComfyUI).

- **Folder**: [`compress_png_to_webp_and_keep_comfyui_workflow/`](./compress_png_to_webp_and_keep_comfyui_workflow/)
- **Documentation**: [`compress_png_to_webp_and_keep_comfyui_workflow/README.md`](./compress_png_to_webp_and_keep_comfyui_workflow/README.md)
- **Key Features**: Multi-core batch processing, EXIF metadata mapping (`ImageDescription` and `Make`), smart resume, ~85% disk space reduction.

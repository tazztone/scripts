# Immich Create Album from Log

A companion Python utility to create or update an Immich album from a previously saved `timelapse_stacking_last_run.json` record.

---

## 🎯 Purpose & Problem Solved

After running the [timelapse_stacking.py](file:///home/tazztone/_coding/scripts/python/immich-api/timelapse_stacking.py) wizard, you might want to create a new album, rebuild a previously deleted album, or switch between **Index Mode** (cover frames only) and **Collection Mode** (all frames) without re-running the entire detection and stacking pipeline.

This script:
1. **Reads** `timelapse_stacking_last_run.json` in the same directory.
2. **Prompts** for target album name (default: `⏱ Timelapse Stacks`).
3. **Finds or Creates** the album in Immich automatically.
4. **Extracts IDs** based on your selected mode:
   - **Mode [1] - Index Mode (Recommended)**: Extracts only the first photo (cover frame) of each stacked timelapse sequence.
   - **Mode [2] - Collection Mode**: Extracts every single asset ID across all stacked timelapses.
5. **Batch adds** assets to the album in chunks of 500.

## 📋 Requirements & Dependencies

- Python 3.8+
- Python packages:
  - `requests`
  - `python-dotenv`
- A valid `timelapse_stacking_last_run.json` file generated by `timelapse_stacking.py`.

Install dependencies:
```bash
pip install requests python-dotenv
```

## ⚙️ Configuration

Uses environment variables configured in `.env` (or `.env.example`):

```dotenv
IMMICH_BASE_URL=http://localhost:2283
IMMICH_API_KEY=your_api_key_here
```

| Variable | Required | Description | Example |
| :--- | :--- | :--- | :--- |
| `IMMICH_BASE_URL` | Yes | Base URL of your Immich instance | `http://localhost:2283` |
| `IMMICH_API_KEY` | Yes | API key generated in Immich Account Settings | `v8...` |

## 🚀 Usage

Run the script from the terminal:

```bash
python3 create_album_from_log.py
```

### Interactive Steps

1. **Enter Album Name**: Press `Enter` to use default `⏱ Timelapse Stacks` or type a custom name.
2. **Choose Mode**:
   - `[1]` **Index Mode**: Creates a clean gallery where each photo represents a different timelapse sequence.
   - `[2]` **Collection Mode**: Adds all individual photo frames from all sequences.

## 🔍 Technical Details & API Endpoints

- **`GET /api/albums`** — Checks if an album matching `album_name` already exists.
- **`POST /api/albums`** — Creates the album if it does not already exist.
- **`PUT /api/albums/{album_id}/assets`** — Performs batched additions of asset IDs (500 per request). Immich automatically handles de-duplication.
